*[BSP]: Board Support Package — bir kartı çalıştırmak için gereken çekirdek, önyükleyici ve donanım ayarları paketi
*[SBOM]: Software Bill of Materials — yazılım malzeme listesi
*[SPDX]: Software Package Data Exchange — lisans ve SBOM bilgisi için standart biçim
*[CVE]: Common Vulnerabilities and Exposures — kamuya açık güvenlik açığı kimliği
*[LTS]: Long Term Support — uzun süreli destek
*[OE]: OpenEmbedded
*[OE-Core]: OpenEmbedded-Core — tüm Yocto tabanlı sistemlerin ortak çekirdek katmanı
*[SDK]: Software Development Kit — uygulama geliştiricileri için çapraz derleme araç takımı
*[eSDK]: Extensible SDK — devtool içeren genişletilebilir SDK
*[QEMU]: Donanım olmadan sistemi bilgisayarda çalıştıran emülatör
*[CRA]: Cyber Resilience Act — AB Siber Dayanıklılık Yasası
*[sstate]: shared state — önceden derlenmiş görev çıktılarının önbelleği
*[rootfs]: root file system — kök dosya sistemi
*[WSL]: Windows Subsystem for Linux
*[CI]: Continuous Integration — sürekli entegrasyon
*[OTA]: Over-the-air — uzaktan (kablosuz) güncelleme
*[SPL]: Secondary Program Loader — U-Boot'un DRAM'i başlatan küçük ön aşaması
*[TPL]: Tertiary Program Loader — SPL'den önceki en küçük U-Boot aşaması
*[PSCI]: Power State Coordination Interface — işlemci çekirdeklerini açma/kapatma için ARM ürün yazılımı arayüzü
*[FIT]: Flattened Image Tree — U-Boot'un çok parçalı, özetli ve imzalanabilir imaj biçimi
*[DTB]: Device Tree Blob — derlenmiş aygıt ağacı
*[UART]: Universal Asynchronous Receiver-Transmitter — seri port birimi
*[MMIO]: Memory-Mapped I/O — bellek eşlemeli giriş/çıkış
*[RTC]: Real-Time Clock — pille beslenen donanım saati
*[NTP]: Network Time Protocol — ağ üzerinden saat eşitleme
*[TFTP]: Trivial File Transfer Protocol — önyüklemede kullanılan basit dosya aktarım protokolü
*[NFS]: Network File System — ağ dosya sistemi
*[DHCP]: Dynamic Host Configuration Protocol — otomatik adres yapılandırması
*[UEFI]: Unified Extensible Firmware Interface — PC ve sunucu ürün yazılımı arayüzü
*[ACPI]: Advanced Configuration and Power Interface — x86 donanım tanım tabloları
*[eMMC]: embedded MultiMediaCard — kart üzerine lehimli flaş depolama
